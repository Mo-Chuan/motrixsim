# ⚡ GPU Module

The `motrixsim.gpu` package provides GPU-accelerated multibody physics simulation, built on NVIDIA Warp. Its public API closely mirrors the CPU version (`motrixsim`); see [CPU vs. GPU API Differences](../../user_guide/gpu_version/api_differences.md) for the deltas.

For the full usage guide, system requirements, and examples: [GPU Version Guide](../../user_guide/gpu_version/index.md).
